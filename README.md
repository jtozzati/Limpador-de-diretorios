# 🧹 Limpador de Diretórios

Um script simples em Python para limpar automaticamente diretórios, removendo arquivos desnecessários e organizando o espaço.

## 📌 Funcionalidades

- Remoção de arquivos temporários
- Exclusão de pastas vazias
- Limpeza personalizada por tipo de arquivo
- Execução rápida via script principal
